Algorithm: SHA-256 Password Hashing
===================================

Input: User password as a string
Output: SHA-256 hash as a hexadecimal string

1. Start

2. Receive the user's password as a string.

3. Convert the password string into bytes using UTF-8 encoding.

4. Initialize the SHA-256 message-digest algorithm using `MessageDigest`.

5. Pass the UTF-8 password bytes to the SHA-256 digest function.

6. Generate the resulting 256-bit hash value as a byte array.

7. Create an empty string builder to store the hexadecimal representation of the hash.

8. Process each byte of the generated hash:

   * Convert the byte to an unsigned hexadecimal value.
   * Add a leading `0` when the hexadecimal value contains only one character.
   * Append the hexadecimal value to the string builder.

9. Return the complete hexadecimal hash string.

10. If the SHA-256 algorithm is unavailable, raise a runtime exception indicating that the algorithm was not found.

11. Stop
